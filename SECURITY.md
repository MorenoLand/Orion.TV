# Security policy

Do not disclose suspected vulnerabilities in a public issue.

Use the repository's GitHub Security Advisories page for a private report when private reporting is enabled: <https://github.com/MorenoLand/Orion.TV/security/advisories/new>.

Include the affected commit, platform, reproduction steps, impact, and any proof-of-concept needed to validate the report. Do not include credentials, private URLs, or unrelated personal data.
